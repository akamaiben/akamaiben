## Open source

- [agent-scorecard](https://github.com/dxdev-inc/agent-scorecard): answers "of the work I handed to agents, how much actually finished, and how much can I trust?" It runs on synthetic data out of the box, and you point it at your own log to get real numbers.
- [agent-memory](https://github.com/dxdev-inc/agent-memory): keeps a folder of agent memory files healthy. It checks the always-loaded index against size limits, finds orphaned files and dead links, and flags near-duplicates for a cleanup you can undo.
- [agent-guardrails](https://github.com/dxdev-inc/agent-guardrails): small hooks that stop a coding agent before it makes a known mistake, like an endless wait loop or printing a secrets file into the conversation. They are guards against habits, not a security sandbox.
